# 홋카이도 신혼여행 플래너

구글맵과 연결해서 **실제 운전시간·거리**, **방문 요일의 영업시간·휴무**, **폐업/임시휴업 여부**까지 확인하며 일정을 짜는 개인용 웹앱.

## 쓰는 법

웹 버전(GitHub Pages)을 열고 일정 저장소에 연결하면 어느 기기에서나 같은 일정을 보고 고칠 수 있어요.
일정과 구글 키는 이 코드 저장소에 없고 작성자 계정의 비공개 저장소에 있어요. 그 저장소만 열 수 있는 토큰이 있어야 읽고 쓸 수 있고, 저장할 때마다 이력이 남아요.
앱의 설정에서 연결 링크를 복사해 보내면 다른 사람도 같은 일정을 함께 볼 수 있어요.

개발할 때는 아래처럼 맥에서 띄워요. 이때 일정은 `data/trip.json`을 써요.

```bash
npm install
npm start
```

## 구글 연동 (권장)

앱 오른쪽 위 **"무료 모드 · 구글 연결하기"** → API 키 입력. 발급 방법은 설정 창에 단계별로 나와 있어요.
필요한 API: Maps JavaScript API, Places API (New), Routes API. 개인 여행 계획 정도면 월 무료 한도 안이에요.

| | 구글 키 있음 | 키 없음 (무료 모드) |
|---|---|---|
| 지도 | 구글 지도 (한국어 지명) | OpenStreetMap |
| 운전시간 | Routes API 실제 경로 | Valhalla 경로 × 보정값 (구글과 대략 ±15%) |
| 장소 검색 | 구글 자동완성 (한국어 OK) | Photon (일본어·영어 이름 위주) |
| 영업시간·휴무·폐업 | 구글에서 자동 | 직접 입력 |
| 대중교통 | 직접 입력 (구글 경로 API가 일본 대중교통을 주지 않아요) | 직접 입력 |

키 없이도 모든 기능이 돌아가요. 키를 넣으면 기존 무료 추정 경로가 구글 경로로 다시 계산돼요.

## 할 수 있는 것

- **일자별 타임라인**: 카드를 끌거나 ▲▼로 순서 변경 → 도착·출발 시각, 이동시간이 바로 다시 계산. 날짜 위에 놓으면 그날로 이동. 폰에서는 번호 손잡이를 끌어요
- **자동 배치**: 장소를 넣거나 다른 날로 옮기면 그날 동선에서 가장 맞는 자리에 들어가요. 주차장에 세우고 걷는 구간 근처면 그 안에 도보로 들어가고, 시간이 모자라면 체류를 줄여요. 그날 동선과 너무 멀면 더 맞는 날을 알려줘요
- **제목 자동 연동**: 그날 제목은 일정에서 만들어져요. 직접 쓰면 그 제목이 유지되고, "일정에 맞추기"로 되돌릴 수 있어요
- **점심·저녁**: 식당은 도착 시각으로 점심·저녁을 표시하고, 하루 머리글에 그날 식당이 나와요. 비어 있으면 "미정"
- **자동 점검**: 휴무일 방문, 오픈 전 도착(대기 시간 + "오픈 시각에 맞추기" 버튼), 체류 중 마감, 폐업/임시휴업, 일몰 후 운전(야생동물), 하루 운전 과다, 고정 시각(예약·불꽃놀이) 지각, 차를 두고 온 곳에서 운전 시작, 시음·저녁 뒤 운전, 해 진 뒤 오래 걷기, 내비 번호 없는 곳
- **영업시간 기준**: 구글 영업시간을 여행과 다른 계절에 받았으면 "11/5 기준"처럼 표시해요. 공식 시간을 직접 넣으면 구글로 다시 확인해도 그대로예요
- **구간별 이동수단**: 운전 / 도보 / 대중교통 / 직접 입력(택시·페리), 운전엔 주차 여유시간 자동 추가
- **전체 보기**: 7일을 한 화면에 그린 하루 흐름 차트(운전·체류·대기·일몰)
- **테마 후보 지도**: 와이너리·맥주·사케·호수·라벤더·러브레터·온천·털게·치즈케이크·골프 후보를 지역별 분포표와 지도로 비교하고 장소함에 담기 (`src/candidates.ts`)
- **후보와 픽**: 장소 카드의 "＋ 후보"로 같은 자리에 갈 다른 곳(예: 저녁 식당)을 넣어 두면, 카드를 옆으로 밀 때마다 후보가 나와요. 후보마다 바꿨을 때의 도착 시각, 운전 변화, 휴무 경고를 보여주고, 두 사람이 각자 픽한 뒤 "1순위로"를 누르면 일정에 들어가요. 근처 식당 추천(구글)도 받을 수 있어요. 픽 버튼 이름은 설정에서 바꿔요
- **순서 최적화**: 시각 고정과 숙소는 그 자리에 두고 나머지를 옮겨 보며 더 나은 순서를 제안. 주차장에서 걷는 묶음, 차 위치, 식사 시간, 영업시간, 저녁 뒤 이동을 따져요. 옮길 곳이 7곳 이하면 모든 순서를 다 비교해요. 구글 없이도 돌아요
- **숙소 찾기**: 근처 숙소를 평점과 함께 보고 눌러서 바로 적용 (연박·체크인 일정까지 함께 변경)
- **장소함**: 가고 싶은 곳을 모아두고 원하는 날에 추가, 6월 계절 정보 포함
- **폰으로 가져가기**
  - 오프라인 모바일 일정표(HTML 한 장) — 장소마다 구글맵 길찾기 버튼, 렌터카 내비용 전화번호
  - 구글 My Maps용 KML(전체/일자별) — 폰 구글맵 앱 "저장됨 → 지도"에서 보기
  - 일자별 구글맵 경로 링크(경유지 포함)
- **버전 기록**: 저장할 때마다 무엇이 바뀌었는지 기록에 남아요. 예전 시점을 그대로 열어 보고 되돌릴 수 있고, 이름을 붙여 버전으로 따로 보관할 수도 있어요 (`versions/` 폴더, 일정 저장소)
- **버전 비교**: 저장된 버전을 나란히 놓고 숙소·골프·명소·식당을 며칠째에 가는지 한눈에 비교. "다른 곳만 보기"로 차이만 볼 수 있어요
- **톨비**: 운전 구간마다 예상 톨비를 구글에서 받아 구간·하루·전체로 합쳐 보여줘요. 정액권(HEP)이나 주말 할인은 반영되지 않아요
- **체크인·체크아웃**: 숙소 상세에서 체크인·체크인 마감·체크아웃 시각을 넣어 두면, 처음 묵는 날 도착이 마감에 늦거나 빠듯한지, 떠나는 날 체크아웃보다 늦게 출발하는지 자동으로 경고해요
- **여행 중 화면**: 여행 기간에 앱을 새로 열면 오늘 날짜부터 보여주고, 맨 위에 지금 있는 곳과 다음 목적지, 길찾기, 내비용 전화번호·맵코드 복사가 나와요
- **예약 달력**: 일정 카드의 "📅 예약"에 집합 시각과 며칠 전부터 예약할 수 있는지를 넣으면 준비 화면에 날짜순으로 모아 보여줘요. 일정을 옮기면 예약 날짜도 따라가고, 집합 시각에 늦으면 경고해요
- **아침식사**: 숙소 상세에 조식 시간을 넣어 두면 묵은 숙소에서 출발하는 날마다 아침 시간을 잡아 보여주고, 출발이 일러 못 먹으면 경고해요. 날마다 "안 먹음"으로 뺄 수 있어요
- **주차**: 장소마다 무료/유료/근처 유료/주차 불가와 대략 요금, 정보 출처를 표시. 차로 가는 곳에 주차가 안 되면 경고해요. 구글은 유무만 알려주므로 요금은 직접 조사해 넣거나 고칠 수 있어요
- **인터넷이 끊겨도**: 마지막으로 받은 일정을 보기 전용으로 보여주고, 다시 연결되면 최신본으로 돌아가요. 접속 토큰이 막혔을 때도 저장된 일정은 보여요. 지도는 인터넷이 있어야 나와요
- **두 사람이 동시에 고쳐도**: 서로 다른 항목이면 양쪽 수정을 합쳐서 저장해요. 같은 값을 다르게 고쳤을 때만 다른 기기 쪽을 따르고 알려줘요
- 되돌리기(⌘/Ctrl+Z), JSON 백업·불러오기

## 구조

```
src/
  seed.ts              추천 동선·장소 데이터 (좌표, 계절 정보, 팁)
  lib/schedule.ts      일정 계산 + 경고 규칙
  lib/hours.ts         영업시간 판정
  lib/google.ts        Places API (New), Routes API
  lib/free.ts          무료 대체 (Photon 검색, Valhalla/OSRM 경로)
  lib/backend.ts       저장소 (맥 개발 서버 / 웹 버전 비공개 GitHub 저장소)
  lib/revisions.ts     두 일정 비교, 변경 기록 문구, 버전 요약
  lib/placement.ts     자동 배치, 순서 최적화, 주차장 묶음
  lib/merge.ts         동시 수정 합치기
  lib/today.ts         여행 당일 계산 (일본 시각)
  lib/bookings.ts      예약 달력
  lib/export.ts        구글맵 링크, KML, 모바일 일정표
  components/          화면 (CompareView 버전 비교, ParkingInfo 주차)
server/tripStorage.ts  data/trip.json 저장 (Vite 개발 서버 미들웨어)
```
